# Z-Route Redemption DPS — Hero comparator
A tool to compare the DPS (damage per second) of heroes in **Z-Route Redemption**.

[Z-Route Redemption DPS](https://alainsopp.github.io/z-route-dps/)

The website helps players evaluate and compare heroes based on their damage output, making it easier to identify the most effective heroes for their team.

## ✨ Features

- **Hero DPS comparison** — Compare the damage per second of different heroes.
- **Filter by name** — Quickly find a specific hero.
- **Filter by stars** — Narrow down heroes based on their star rating.

## 🎯 Purpose

The goal of this project is to provide players with a convenient way to explore hero DPS values and compare their performance under different conditions.  

Instead of manually checking each hero, users can filter the available heroes and quickly find the information they need.

## 🚀 Usage

1. Use the name filter to find a specific hero.
1. Filter by star rating or level to narrow down the results.
1. Compare the displayed DPS values to help evaluate hero performance.

## 🛠️ Technologies

- HTML
- Web browser

The website is designed to run directly in a browser without requiring a dedicated application.

## 📌 Disclaimer

This is an unofficial fan-made tool for **Z-Route Redemption**.  
It is not affiliated with or endorsed by the game's developers.

DPS values and comparisons are intended to help players evaluate heroes. Actual in-game performance may vary depending on game mechanics and other factors.
